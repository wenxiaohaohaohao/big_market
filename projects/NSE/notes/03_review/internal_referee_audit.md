# Internal Referee Audit

日期：2026-07-28
审查对象：`paper/main.tex`、`paper/appendix.tex`、Model Contract v4、命题台账与数值代码

## 总体判断

当前稿的主问题仍是 **platform access--local capture**：平台化同时改变消费者接入、
本地生产者进入全国市场的机会，以及交易收入的空间归属。NSE 没有替代该问题，
而是为“禀赋条件下的潜在比较优势怎样转化为实际进入、本地组织嵌入和地方收入”
提供理论结构。

模型已经删去不服务这一问题的独立 ACA 状态、完整空间一般均衡、企业异质性、
迁移、平台定价和全国福利。剩余模块均直接进入家庭选择、企业利润、组织选择、
支付流、地方收入或公共基础设施供给。

## 主要审查问题及处理

### 1. 比较优势概念是否严格

正文没有把 \(1/c\)、盈利能力或产业规模称为比较优势。LCA 使用地区和产业两个
维度的相对生产成本定义：

\[
\mathcal C^P_{ij}
=
\frac{c^P_{ij}/c^P_{i0}}
     {c^P_{hj}/c^P_{h0}}.
\]

\(\mathcal C^P_{ij}<1\) 表示地区 \(i\) 在产业 \(j\) 具有 LCA。原文审计后的
概念边界是：

- **LCA**：由禀赋结构决定的相对生产成本优势；
- **ACA / realization**：Lin--Wang (2023) 将交易成本加入后实际出现的生产和
  出口结构称为 ACA；其经验对应是出口参与和 RCA，理论对应是 active-industry
  set。本文的 actual entry and sales 是这一关系在国内市场的对应，不再把 ACA
  与 realization 拆成两个状态；
- **viability**：Lin (2003) 的另一项企业属性，即正常经营企业在开放竞争中不
  依赖持续保护或补贴而获得正常利润。本文的利润条件与其相容，但不另设变量。

因此，正式阈值 \(G_E\) 是 actual-entry threshold。正文不求 \(G_A\)，也不建立
viability threshold。这样既保留 NSE 的生产成本—交易约束逻辑，也避免为术语
完整性增加不服务 access--capture 问题的参照地区方程。

### 2. 是否偏离原始 EL 问题

没有。消费者 CES、平台有效价格、平台支出份额、本地收入含量
\(\omega_C\)、生产者市场接入、组织方式、生产者支付归属 \(\rho_r\)，以及地方
收入递归传播全部保留。与 EL 的分工是：

- EL 在生产收益和留存能力给定时分析 access--capture 与收入传播；
- 本文内生生成生产者进入、组织方式和第一轮本地收入；
- EL 公式只作为末端传播闭合，不再次作为本文的新贡献。

### 3. 每个模块是否有明确理论母体

| 模块 | 理论来源 | 本文的最小修改 |
|---|---|---|
| 消费者 CES 与价格指数 | Dixit--Stiglitz；EL companion | 增加渠道支付流，从而生成 \(\omega_C\) |
| 禀赋与 LCA | Lin；Ju--Lin--Wang；Lin--Wang | 用双重相对生产成本定义 LCA |
| 生产者 CES、固定加成 | Dixit--Stiglitz | 以 \(M(z,G)\) 汇总 producer access |
| 外部平台与本地组织选择 | Ahn--Khandelwal--Wei 的条件性组织排序 | 组织选择同时改变支付所在地 |
| 本地专业化服务与共同固定成本 | Rodríguez-Clare | 将本地嵌入解释为生产者服务和产业联系 |
| 地方收入传播 | Type-II/local-multiplier 文献与 EL | 只保留为 conditional propagation block |
| facilitating state | Lin--Monga；Lin (2011, 2012) | 以 \(G=G_0+I\) 表示 state-enabled 共享基础设施增加；Lin--Wang 只进入 LCA--交易成本--ACA 模块 |

本文不声称完整复制任一母体模型。每个来源只承担其能够支持的局部结构。

### 4. 变量是否仅为闭合而设置

活动模型的对象均进入可观察的选择或支付流：

- \(z\)：降低消费者平台价格并提高 producer access；
- \(G\)：共享的物流、标准、认证和数字基础设施；
- \(c\)：候选产业在给定本地要素价格下的单位生产成本；
- \(d_P,d_L\)：两种组织方式的单位组织服务成本；
- \(f\)：进入全国市场的私人固定成本，包含正常回报要求；
- \(F\)：建立本地嵌入式服务体系的额外共同固定成本；
- \(\ell_A,\ell_P\)：消费者渠道支出中形成当地收入的份额；
- \(\rho_P,\rho_L\)：候选产业销售收入中形成当地收入的份额。

不存在独立“能力指数”、外生留存函数或只为产生目标结论而加入的状态变量。

### 5. 市场接入式是否有经济基础

基准从 outbound iceberg cost 推导：

\[
\tau_O(z,G)=\bar\tau_Oe^{-\psi z-\gamma G},\qquad
M(z,G)=M_0e^{(\sigma-1)(\psi z+\gamma G)}.
\]

\(\bar\tau_O\) 足够大，使所研究区间内 \(\tau_O\geq1\)。基准没有为了强化结果
预设 \(zG\) 交互。可选稳健性才加入 \(\chi^{ext}zG\)，并明确称为扩展。

### 6. 组织选择和支付归属是否被重复计算

\(P/L\) 由同一企业利润比较生成。\(f,F\) 决定进入和组织选择；在基准中它们是
对本地要素和服务的支付，因此不再从地方收入中重复扣除。外部单位平台服务支付
只通过 \(\rho_P\) 扣除一次。\(\rho_L=1\) 是所有本地嵌入服务收入均留在当地的
极化基准；部分平台服务本地化由 \(\lambda\) 稳健性分析处理。

### 7. 收入阈值是否被数值算法制造

没有。阈值算法先枚举 \(G_E,G_L\) 等精确结构事件，再在各连续组织区间使用
Brent 求根。若收入效应在进入或组织转换处跳变，算法返回精确事件，不返回网格
邻点。当前基准因此得到：

\[
G_E=G_R=0.210619,\qquad
G_Y=0.555415,\qquad
G_L=1.090996.
\]

\(G_R=G_E\) 是进入时第一轮生产收入离散增加造成的经济边界，不是数值误差。
正文只无条件声称 \(G_R\leq G_Y\)；严格排序仅适用于两个根位于同一连续组织区间
的情况。

### 8. facilitating state 是否被写成任意产业补贴

没有。命题 4 从初始 \(G_0\) 出发，求跨越既有门槛所需的最小共享基础设施增加
\(I_H=[G_H-G_0]_+\) 及相应真实资源成本。它不求最优 \(I\)，也不声称任何特定
基础设施项目具有全国福利最优性。

外部渠道限制被单独作为条件性政策例子，而不是 NSE 中“保护”的一般定义。它通过
提高外部平台成本诱导本地化，同时恶化消费者接入并提高边际企业的进入门槛；这与
降低真实共享约束的 facilitation 不等价。

这些结果不是 calibration、估计或中国效应大小。

## 对外必须保留的限制

1. 背景产业给定机会成本，未求长期两部门要素再配置；
2. 参照地区成本和全国市场规模外生；actual entry 只是 LCA-to-ACA 的国内市场
   对应，不是国际贸易中的 ACA/RCA 数量测度；
3. 平台价格和平台服务费不由平台最优化决定；
4. 不含企业异质性、迁移、集聚和完整全国福利；
5. 无实际数据，不能用于定量政策评价。

这些边界限定了论文的结论范围，但不使当前稿成为“等待数据的未完成品”。
